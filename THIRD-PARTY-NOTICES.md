## Mod runtime

The feed mod that PalRadar installs is a Lua script that runs inside [RE-UE4SS](https://github.com/UE4SS-RE/RE-UE4SS)
(MIT), the scripting runtime that Palworld's official mod support ships with. UE4SS itself is not part of the
release; PalRadar only places a script in its `Mods` folder.
